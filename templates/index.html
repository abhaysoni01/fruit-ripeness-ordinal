How Ordinal Regression Models Fruit Ripeness

CORAL respects class order and limits predictions to the stages defined by the training dataset.

❌ The Problem with Standard Cross-Entropy

  • Ignores Natural Order: Standard softmax assumes all classes are equidistant in orthogonal space.
  • Equal Penalty: Standard cross-entropy does not account for the distance between ripeness stages.
  • High Mean Absolute Error (MAE): Causes wild off-by-2 and off-by-3 errors that ruin automated sorting supply chains.

✅ The CORAL Solution (Cao et al., 2020)

  • Rank-Consistent Architecture: Uses $K-1$ ordered binary tasks sharing a single weight vector $w$: logit_k = w^T x + b_k.
  • Ordered Threshold Biases: Learnable thresholds enforce rank consistency across boundaries.
  • Monotonic Rank Decoding: The final predicted grade is obtained by summing passed threshold gates: ŷ = ∑ 𝟙[σ(logit_k) > 0.5].

The CORAL Loss Function

The total loss is the mean binary cross-entropy across all rank thresholds, penalizing predictions proportionally to their distance from the true stage:

L_CORAL = - 1 / (N · (K-1)) ∑_i ∑_k [ y_ik · log σ(logit_ik) + (1 - y_ik) · log(1 - σ(logit_ik)) ]

Where y_ik = 𝟙[y_i > k] is 1 if the true ripeness rank exceeds threshold k, and 0 otherwise.

Dataset Specifications

  • Source: Public Kaggle Fruits-Ripeness Dataset (CC0)
  • Fruits: Banana and mango
  • Resolution: 300 × 300 pixels, RGB
  • Backbone: Pretrained ResNet-18 (ImageNet weights)
  • Ripeness labels:
    • Stage 0: Unripe
    • Stage 1: Ripe
    • Stage 2: Overripe
  • Testing: Uses the source-provided test split

Why MAE is the Decisive Metric

The ordinal model treats adjacent ripeness stages as closer than stages separated by larger ripeness differences.

MAE (Mean Absolute Error) reports the average distance between predicted and true stage.
